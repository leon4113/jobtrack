# jobtrack

A personal job application tracker — replaces the spreadsheet.

## Stack

- **Frontend:** React + Vite + TypeScript
- **Backend:** Hono (Node)
- **Database:** SQLite + Drizzle ORM
- **Shared types:** `shared/` package

## Setup

```bash
npm install
npm run dev
```

Client runs on http://localhost:5173, server on http://localhost:3001.
